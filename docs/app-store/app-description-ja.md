# LifeSnap Action App Store説明文ドラフト

LifeSnap Actionは、紙の案内や通知をカレンダー予定に変えるためのアプリです。

学校からのお知らせ、予約案内、請求書、期限のある書類などを撮影、または写真から選択すると、予定に関係する日付、時間、タイトル、場所、メモを抽出します。内容を確認してから、iPhoneのシステムカレンダーに追加できます。

## 主な機能

- カメラで書類を撮影、または写真ライブラリから画像を選択
- 画像を送信する前に、送信先とAI解析への同意を毎回確認
- 抽出された予定内容を追加前に確認
- 確認した予定をシステムカレンダーへ追加
- 明確な予定、確認が必要な予定、予定が見つからない書類を判定
- アカウント、ログイン、ダッシュボード、書類アーカイブ、クラウド同期、サブスクリプションは不要

## プライバシー概要

画像は、ユーザーが送信前の確認画面で同意した場合だけ、予定抽出のためにLifeSnapバックエンドとGoogle Geminiへ送信されます。LifeSnapは画像や抽出内容を永続保存しません。Google Gemini Paid Serviceでは入力・出力はGoogle製品の改善に使われませんが、安全性、不正利用防止、法的義務のために限定された期間ログ処理が行われる場合があります。カレンダーアクセスは、ユーザーが確認した予定を追加するためだけに使用します。
